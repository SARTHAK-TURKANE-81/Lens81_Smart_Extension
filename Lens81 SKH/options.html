Forgot your passcode?

Classification runs through your own API keys: OpenRouter, Google Gemini, xAI Grok, or Groq, mixed and matched per row. Keys stay in this browser and are sent only straight to whichever provider that row uses, never bundled into the extension, never routed anywhere else. Configure 1–5 provider + key + model rows; every configured model classifies each paper in parallel and the results are combined into a single ensemble prediction. Check "only use if needed" on a row to hold that key back as a backup, only spending it when the others fail.

Add at least one key and model below, then hit Test to turn on classification.

Quick picks: a fast, cheap default model per provider:

  • OpenRouter: ~anthropic/claude-haiku-latest (self-updating, won't go stale)
  • Google Gemini: gemini-2.5-flash
  • xAI Grok: grok-4-fast
  • Groq: llama-3.3-70b-versatile

Avoid OpenRouter's :free models (capped ~20 requests/minute) and any model with mandatory reasoning (slower, no accuracy benefit here). Model catalogs and slugs change over time for every provider, so double-check the current one on the provider's own site rather than trusting a hardcoded default. Whichever provider you pick, click that row's Test button after filling it in.

Citation Finder (optional AI relevance check)

Highlight → Find Citation is free by default: keyword matching only, no AI, no cost, using whatever's configured above or nothing at all. Add a separate key here to let an AI double-check each candidate's true relevance before showing it (catches papers that share vocabulary with your passage without actually being on-topic). This key is used only for citation checks, never for classification, and never mixed with the model rows above. Leave it blank to keep citation search fully free.

0–100

A candidate paper needs at least this much combined text-similarity confidence before it's suggested as a citation. Lower it if you're getting too few results (more false positives); raise it if you're seeing weak or unrelated matches. Default is 42.

Cached classifications

Results are cached for 30 days per paper title, so revisiting a search won't re-spend API calls.

Page protection

This page holds your API keys. A passcode stops someone else using this same browser from opening Settings and reading them, but the keys themselves are still stored in plain form for the extension to use automatically. It won't stop someone with direct access to this browser's developer tools.
